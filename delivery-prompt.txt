把《一笔打烊》的“保龄球馆的最后一单”做成打开即玩的网页小游戏。以仓库中的 visuals/one-stroke-street.html 为起点，复用这一关的布局和碰撞规则。成品只交付根目录的 index.html。

【美术规则】
画面是一座正侧视的纸板商业街。纸白 #F7F2E8 做底，墨黑 #252724 画重物和轮廓，蓝色 #2168A3 标记目标房间，橙色 #BC491B 标记卡扣和当前笔迹。远景用 15% 不透明度的墨色。主轮廓 2 个逻辑像素，内部细节 1 个。
靠形状也能认出每个物件。目标房间有三扇亮窗，卡扣画成同心圆，保龄球留三个指孔，弹板上画起跳箭头。用同一套内联 SVG 图形复用这些部件。
落笔时让卡扣轻响。房间受撞后窗灯熄灭、外壳碎开，每间最多飞出六片纸屑。纸屑只作视觉反馈。最后一间碎裂时顿约 80 毫秒，再让屋檐落地。沿用可手动开启的合成音效。

【玩法】
本关限一笔。玩家用鼠标或手指拉出最长三格（144 个逻辑单位）的直线。拖动时高亮将命中的卡扣和房间，松手后同时拆除。空划保留笔数，“重画”随时恢复初始布局。目标是一笔拆完街两边共四间亮房。

【部署架构】
保留 600 × 328 的逻辑场景，按容器等比缩放，将指针坐标换算回场景坐标。输入使用 Pointer Events，模拟按 1/120 秒固定步长推进，requestAnimationFrame 驱动显示。通关由房间实际拆除数判定。
使用 Node.js 22.18.0、npm 11.7.0、esbuild 和 Playwright。把关卡与命中、物理、输入、SVG 渲染、音效分别放入 src/。提供 dev、build、preview、test 脚本并提交依赖锁文件。
将样式、SVG 和打包后的脚本内联到完整的 HTML，使用系统字体。同一个成品既能双击离线试玩，也能在 GitHub Pages 项目子路径运行。构建输出根目录 index.html 和字节相同的 dist/index.html。
发布源设为 GitHub Actions。main 推送后从锁文件安装环境，运行桌面 Chromium、移动 Chromium 和 WebKit 测试，通过后只发布 dist/。拉取请求仅执行验证。把安装、手机联调、构建、发布及回滚步骤写入 README。

【交付验收】
每种拆法都从新局开始验证。只划左扣，球滚进左侧空巷，拆掉 0/4。两扣同划，棚和球平落，拆掉 0/4。只划右扣，球砸穿本楼、借弹板飞过街，拆掉 4/4。
在桌面和 360 像素宽的手机视口直接拖线验证。划空后仍有一笔，倒塌中点“重画”可立即重试。断网并重新打开 index.html，也能完成上述过程。
